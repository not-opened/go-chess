# assets — 바둑·체스·장기 2.5D 보드·기물

2026-11-28 하이디(CCO/CFO)가 구글 드라이브로 납품한 웹 2호용 2.5D 에셋과, 그것을 이 사이트에

## 파생 파일 (납품 원본에서 만든 것)

| 파일 | 원본 | 만든 이유 |
| --- | --- | --- |
| `go_board_wood.webp` | `go_board_tile_kaya.webp` | 납품 타일은 교차선과 화점이 찍힌 '한 칸' 그림입니다. 그대로 반복하면 9×9 바둑판의 화점 5곳과 어긋나 엉뚱한 자리에 점이 생기므로, 한 사분면의 나뭇결만 남겨(명암은 눌러서) 이음매 없이 반복되게 만든 배경 텍스처입니다. 교차선·화점은 `index.html` 의 SVG가 정확한 좌표로 그립니다. |
| `chess_king_dark.webp` | `chess_king.webp` | 납품 킹은 밝은 메달(백)뿐이라 흑 킹용으로 원판과 실루엣 색만 바꿔 만들었습니다. |

| `chess_knight_white.webp` | `chess_knight.webp` | 납품 나이트는 어두운 메달(흑)뿐이라 백 나이트용으로 색만 바꿔 만들었습니다. |

## 미납품 기물 처리

납품분은 체스 3종(킹·퀸·나이트)과 장기 궁 2종뿐입니다.

- **체스 룩·비숍·폰**: 납품 메달과 같은 규격(원판 지름 32, 금테, 실루엣)으로 `index.html` 의
  `chessPieceGroup()` 이 SVG로 그립니다. 같은 판에 나란히 놓아도 이질감이 없습니다.
- **장기 차·포·마·상·사·졸**: 납품 궁 타일과 같은 팔각 나무판·금테·측면 두께로
  `janggiTileGroup()` 이 SVG로 그립니다.
- 두 경우 모두 그림을 못 받아왔을 때(로컬 `file://` 등)를 대비해 같은 SVG가 대체 경로로 쓰입니다.

색은 납품본에서 그대로 뽑았습니다 — 한(漢) `#a8231f`, 초(楚) `#2a5b95`, 메달 원판 `#f9f0e1`/`#2e3543`,
금테 `#c3a97c`, 실루엣 `#382d1e`/`#f3deb3`.
